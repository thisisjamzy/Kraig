Dreda Audit Report Implementation

Core Formulas (Copy-Paste Ready)

Financial Position

NET_WORTH = sum(wallet.balance) - sum(debt.currentBalance) LIQUID_ASSETS = sum(wallet.balance for all wallets) MONTHS_OF_EXPENSES = LIQUID_ASSETS / avg(monthly_expense for last 3 months) SAVINGS_RATE = ((total_income - total_expense) / total_income) * 100 EXPENSE_RATIO = (total_expense / total_income) * 100

Budget Performance

BUDGET_VARIANCE = ((actual_spend - budgeted_amount) / budgeted_amount) * 100 CONSISTENCY_SCORE = count(months where variance in [-10%, +10%]) / total_months * 100

Spending Volatility

MEAN = sum(monthly_spend) / 12 STD_DEV = sqrt(sum((monthly_spend - MEAN)^2) / 12) COEFFICIENT_OF_VARIATION = (STD_DEV / MEAN) * 100

Debt Metrics

DEBT_TO_INCOME_RATIO = (total_debt / (monthly_income * 12)) * 100 DEBT_PAYMENT_RATIO = (total_monthly_debt_payments / monthly_income) * 100 MONTHS_TO_PAYOFF = debt.currentBalance / avg(monthly_repayment for last 3 months)

Thresholds & Color Coding

Savings Rate Status

< 0%: RED "Spending more than earning" 0 - 10%: RED "Barely saving" 10 - 15%: YELLOW "Modest savings" 15 - 20%: YELLOW "Acceptable but not enough" 20 - 30%: GREEN "Good savings rate" 30%+: GREEN "Excellent savings"

Months of Expenses (Emergency Fund)

0 - 0.5: RED "CRITICAL" 0.5 - 1: RED "LOW" 1 - 2: YELLOW "FAIR" 2 - 3: YELLOW "GOOD" 3 - 6: GREEN "EXCELLENT" 6+: GREEN "VERY SAFE"

Coefficient of Variation

< 10%: GREEN "Predictable" 10-20%: YELLOW "Somewhat variable" 20-40%: RED "Highly variable" > 40%: RED "Chaotic"

Wasteful Spending Detection

Dining/Entertainment Alert

IF dining_percent > 5%: YELLOW "Watch" IF dining_percent > 8%: ORANGE "High" IF dining_percent > 12%: RED "Excessive"

Subscription Creep Detection

IF subscriptions > 15K/month: FLAG "Bloated" IF new_subscriptions > 0: FLAG "Creep detected" IF unused (0 usage in 60 days): RED "CANCEL"

Shopping/Impulse Buying Alert

IF shopping_percent > 3%: YELLOW "Watch" IF shopping_percent > 5%: ORANGE "Elevated" IF shopping_percent > 7%: RED "Excessive" IF CV > 40% AND percent > 3%: RED "Impulse pattern"

Presentation Rules

Stat Cards

Font size: 48px value, 12px subtitle Color: Green (↑), Red (↓), Yellow (→) Include: Value | Trend arrow | % change | Comparison

Budget Variance Table

Columns: Category | Budget | Actual | Var % | Status Color: Green (under), Yellow (0-10%), Red (>10%) Sort by: Variance % descending

Volatility Analysis Table

Columns: Category | Avg | Std Dev | CV % | Volatility | Issue Sort by: CV % descending Color: Green CV<15%, Yellow 15-30%, Red >30%

Red Flag Alerts (Rules Engine)

Alert 1: Net Worth Negative & Expense Ratio High IF net_worth < 0 AND expense_ratio > 75%: FLAG: "Debt is growing because expenses too high"
Alert 2: Emergency Fund Low & Discretionary High IF months < 2 AND discretionary > 8%: FLAG: "Underfunded for emergencies but high discretionary"
Alert 3: Savings Rate Declining IF savings_this_month < last_month < 2_mo_ago: FLAG: "Savings declining, creeping expenses detected"
Alert 4: Chronic Overage (2+ months) IF category_variance > +25% for 2+ consecutive_months: FLAG: "Pattern detected, needs intervention"
Alert 5: Volatility Too High IF cv > 30% for discretionary_category: FLAG: "Budget black hole, enforce weekly caps"

Key Implementation Notes

  • All numbers rounded: Math.round() or .toFixed(n)
  • Currency formatting: toLocaleString with thousand separators
  • Percentage formatting: 1-2 decimals (33%, 23.6%)
  • Trend arrows: ↑ (green), ↓ (red), → (neutral)
  • Annual impact mandatory: every variance must show "Annual cost"
  • Specific actions required: never vague advice
  • Expected outcomes: each action includes measurable outcome
  • Motivation through life outcomes: connect to debt payoff, goals, emergency fund
  • Every section must have a clear ask
